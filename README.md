## 🗿 3D 建模：歪毛小女仆

照着一张 Q 版立绘，用 Blender 的 Python API（bpy）从零建出来的角色。

- **99 个物体 / 56,806 面**，全部程序化生成的几何体 + 纯色材质
- **没有素材库、没有贴图文件、没有用付费 3D 生成器**
- 导出 glTF 2.0（`.glb`，2.79 MB），能直接拖进任何 3D 软件或 three.js
- 自己写了一个**双击就能 360° 转着看**的自包含查看器（模型全内联，不联网）
